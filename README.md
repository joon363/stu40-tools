## 🛠️ 제공 도구 안내

### 1. [지킴이](file:///c:/Users/joon363/dev/stu40/stu40-tools/지킴이/README.md)
- **개요**: 학생회 국원들의 구글 설문 응답(가능한 요일 및 시간대) 데이터를 바탕으로, 공정하고 최적화된 지킴이 시간표를 자동 생성하는 도구입니다.
- **주요 기능**:
  - **1인 1타임 배정**: 모든 국원이 고르게 1타임씩 배정되도록 강제
  - **슬롯당 정원 보장**: 30개 슬롯(월~금 5일 × 6개 교시)에 각 2명씩 총 60석 완벽 매칭
  - **국서 중복 방지**: 같은 슬롯에 동일한 소속 국 인원이 겹치지 않도록 자동 분산
  - **최신 제출 반영**: 설문 수정으로 인한 중복 응답 시 최신 타임스탬프 기준 자동 필터링
  - **다각도 산출물 제공**: 최종 시간표 그리드, 슬롯별 전체 가용자 명단, 개인별 배정 내역 엑셀 파일 자동 출력
