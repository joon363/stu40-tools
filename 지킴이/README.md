# 지킴이 시간표 자동 배정 시스템

총학생회 국원들의 수업 시간 외 공강/가능 시간 설문 응답을 분석하여, 공정하고 효율적인 지킴이 시간표를 자동으로 생성하는 도구입니다.

---

## 📌 26-2학기 배정 현황 및 분석

### 1. 인원 수급 및 정원 일치도
- **설문 응답**: 총 64건 (4건 중복 재제출자: 최신 응답 자동 반영)
- **실제 고유 인원**: **정확히 60명**
- **필요 정원**: 총 30개 슬롯 (월~금 5일 × 6개 시간대) × 슬롯당 2명 = **정확히 60석**
- **결과**: 모든 국원이 **1인 1타임**씩 배정되면 공석이나 초과 인원 없이 **100% 매칭**됩니다.

### 2. 슬롯 구성 (총 30개 슬롯)
- **요일**: 월, 화, 수, 목, 금
- **시간대 (6개 교시)**:
  - `11:00-12:20`
  - `12:25-1:50`
  - `1:55-3:20`
  - `3:25-4:50`
  - `4:55-6:20`
  - `6:25-7:50`

### 3. 슬롯별 가용 인원 분포 현황
모든 슬롯에 최소 7명 이상의 지원자가 있어 배정 풀이 충분합니다.
- **최소 지원 슬롯**: `수요일 11:00-12:20` (7명)
- **최대 지원 슬롯**: `수요일 6:25-7:50` (31명)
- **개인별 가능 슬롯 수**: 최소 2개 ~ 최대 18개 (평균 9.4개)

## 🧠 배정 알고리즘 원리

1학기 phase 2 배정 결과(`1학기/final_assignment.xlsx`)를 연동하여, **동일 인물의 경우 1학기 때와 요일 및 시간대가 최대한 먼 슬롯에 우선 배정**되도록 고도화되었습니다.

1. **중복 제출자 자동 정제**:
   - 시간표 수정으로 여러 번 제출한 경우(예: `강지혜(최종)` 등 수식어 포함), 최신 응답 1건만 정확히 유지합니다.
2. **1학기 배정 위치 대비 거리 최대화 (Distance Maximization)**:
   - 1학기 phase 2에서 배정받았던 요일과 교시 인덱스를 기준으로 거리 점수(`요일 차이*2 + 교시 차이`)를 계산합니다.
   - 1학기 때 근무했던 요일/시간대와 가장 거리가 먼 슬롯을 우선적으로 배정하여 특정 요일·시간대 편중을 방지합니다.
3. **1학기 파트너 중복 회피 (Partner Rotation)**:
   - 1학기에 같은 슬롯에 배정되었던 파트너 국원과 2학기에 다시 같은 조로 묶이지 않도록 페널티를 부여하여 자동 회피합니다.
4. **소속 국 중복 배제 (Phase 2.1)**:
   - 동일 슬롯에는 서로 다른 국(부서) 소속 국원 2명이 짝을 이루도록 강제합니다.
5. **희귀 슬롯 및 제약 큰 국원 보호**:
   - 가용 후보가 적은 희귀 슬롯을 먼저 채우고, 지원 가능한 슬롯이 극도로 적은 국원이 공석으로 밀리지 않도록 우선 보호합니다.
6. **고속 몬테카를로 셔플 최적화 (Fast Sampling Optimization)**:
   - 150회의 셔플 시뮬레이션을 순간적(0.2초)으로 수행하여, 모든 필수 제약조건을 100% 충족하면서 **거리 점수 총합이 가장 높은 최적의 조합**을 자동으로 선별하여 저장합니다.

## 🚀 사용 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
```

### 2. 배정 실행
`지킴이` 폴더 안에서 다음 명령어를 실행합니다:
```bash
python assign_26_2.py
```

### 3. 결과 확인
`output_26_2/` 폴더에 생성된 엑셀 파일들을 확인합니다:
1. `final_assignment.xlsx`: 학생회실에 부착하거나 공지할 수 있는 최종 시간표 형식 (각 셀에 2명씩 배정).
2. `person_assignment.xlsx`: 국원별로 본인의 배정 시간대를 검색/확인할 수 있는 명단.
3. `all_available.xlsx`: 이후 대타나 교환이 필요할 때 해당 시간대에 누가 가능한지 즉시 찾아볼 수 있는 전체 가용자 명부.

## 🔄 1학기 대비 2학기 데이터 포맷 변경 사항
| 항목 | 1학기 (`26-1`) | 2학기 (`26-2`) |
| :--- | :--- | :--- |
| **설문 컬럼 구조** | 열이 시간대, 셀 값이 요일(`월, 수`) | 열이 요일(`[월] ~ [금]`), 셀 값이 시간대(`12:25-1:50, ...`) |
| **시간대 표기** | `12:25~13:50` (24시간제/`~`) | `12:25-1:50` (12시간제/`-`) |
| **국(부서) 정보** | 코드상 이름에 `(국)` 형태 파싱 전제 | `이름`과 `국` 컬럼이 별도로 명확히 분리됨 |
| **스크립트 처리** | `1학기/make_slot.py` | `assign_26_2.py` (포맷 어댑터 및 중복 정제 내장) |
